# Quest Studio

A browser-based RPG maker for students. Draw tiles and characters, build maps, and program events in **JavaScript or Python**. Each script is automatically turned into **pseudocode** and a **flowchart**.

**Open it:** https://anwhel.github.io/9-gd/ (served from [`rpg-maker/`](rpg-maker/))

See [`rpg-maker/README.md`](rpg-maker/README.md) for features, the command reference and the file layout.
